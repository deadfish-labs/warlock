# 10 — Roadmap

The order we build in. The game comes first; the platform around it comes later. Decided by the owner on 2026-10-22.

## Phase 1 — The game

The first version of Warlock as defined in chapter 09: five characters, every spell and item, Round (with duel and
teams), Deathmatch, Avatar and King, 2–12 players, web (keyboard + mouse) and mobile (joystick + touch buttons), on an
authoritative Colyseus server (chapter 08). Players join a match from a simple list or an invite link. At the end of the phase: in-game voice chat
(chapter 14).

## Phase 2 — Accounts, cosmetics and league

In the first release, but built after the core game works:

- **Player accounts** (name, login, progress kept between matches).
- **Tokens and cosmetics:** tokens earned every round, spent on looks only (the "Lich" look, titles, hats, fireball
  colours). Nothing that changes the game.
- **League:** match statistics recorded on our server, a ranking, and the league / competitive rule presets of the
  original (`-league`, `-cm`, `-mgl`).

## Phase 3 — The lobby platform

A lobby that sits **above** the games, so Warlock is one game among several (chapter 11).

## Later

- Bots for practice and empty slots.
- More games on the platform.
