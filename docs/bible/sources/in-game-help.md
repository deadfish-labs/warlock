## Game mechanics (default values)

The map notes that these are defaults and some can be changed at startup (see chapter 05).

**Point system**
- 2 points for every victory (winning a round)
- 1 point for every kill

**Gold system**
- 2 gold for a victory
- 1 gold for the damage dealer
- 2 gold for a pure kill
- 1 gold for an assisted kill
- 1 gold for an assist kill

The difference between "assisted kill" and "assist kill" is explained by the script (chapter 05); here it is quoted as
written.

## Commands

| Command | What it does |
|---|---|
| `-cam[numbers]` | Sets camera zoom (standard 0) |
| `-splitter` | Changes splitter mode |
| `-oath [numbers]` | Sets oath sensitivity |
| `-stats` | Displays move speed and other information |
| `-fbc [color]` | Sets the fireball colour (standard red); pink, blue, green or red |

What "splitter mode" and "oath sensitivity" control is explained in chapters 01 and 06.
